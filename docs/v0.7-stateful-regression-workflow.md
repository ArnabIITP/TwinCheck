# TwinCheck v0.7 Stateful Regression Workflow

This milestone turns an existing stateful HTTP finding into a portable regression pack that can be replayed in CI.

## Acceptance criteria

- Export the selected finding's request sequence, optional reset workflow and pinned compatibility contract.
- Verify source and canonical hashes before exporting and pack file hashes before replay.
- Keep response observations and request-header values out of the pack.
- Require explicit loopback target URLs and a side-effect acknowledgement during replay.
- Run the full test suite on Python 3.11, 3.12 and 3.13 before release.

The full implementation is being prepared for this branch. A documentation-only commit does not count as the milestone being complete.
