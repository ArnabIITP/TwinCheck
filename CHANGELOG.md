# Changelog

## 0.1.0 — Initial prototype

- Add deterministic input generation for mixed, text, integer and JSON-like inputs.
- Add shell-free CLI execution with stdin and `{input}` argument support.
- Compare stdout, stderr, exit code and timeout behavior.
- Add normalization options, UTF-8 corpus loading and bounded delta-debugging minimization.
- Add JSON report output, examples, tests, CI and project documentation.

This release is experimental. See the README's current limits before using it in automated workflows.
