# Code of Conduct

We are committed to a welcoming, respectful and constructive community.

Examples of expected behavior include being considerate, giving actionable feedback, accepting corrections gracefully, and focusing discussion on technical issues rather than people.

Unacceptable behavior includes harassment, discriminatory language, personal attacks, doxxing, and publishing private information without consent.

Project maintainers may edit or remove contributions that violate this code and may restrict participation where necessary. Report concerns privately to the repository maintainer.

This code is adapted in spirit from common open-source community standards; it is intentionally concise for this early project.
